# Кодекс права (рабочее название)

Учебный сайт: реальные российские гражданские дела, разобранные понятным языком —
факты, доказательства, применённые нормы права, решения по инстанциям, со ссылкой
на первоисточник у каждого опубликованного дела.

Архитектура — та же, что у `kodeksdeneg`/`kodeksdetstva`: статический генератор
на чистом Node.js (без зависимостей), `node scripts/build.mjs` → `dist/`.

## Запуск

```bash
npm --prefix ~/WebstormProjects/Nick/kodeks-prava run build
npm --prefix ~/WebstormProjects/Nick/kodeks-prava run dev   # соберёт и поднимет локально на :4000
```

## Структура контента

- `content/cases.mjs` — дела. `status: "published"` — карточка готова и сверена
  с источником, есть все поля. `status: "discovered"` — тема отобрана, факты
  ещё не исследованы: у такой записи намеренно нет ни номера дела, ни цифр —
  ничего не выдумываем, пока не проверено (см. CLAUDE.md).
- `content/pages.mjs` — статические разделы (судебная система, профессия
  адвоката, книги, о проекте).

## Как добавить дело

1. Найти реальное дело в официальном/проверяемом источнике (sudact.ru,
   legalacts.ru, определения ВС РФ, обзоры Президиума ВС РФ).
2. Сначала добавить строку со `status: "discovered"` — просто тема и категория.
3. Изучить источник, заполнить все поля (см. первое дело в `cases.mjs` как
   образец структуры), проставить `status: "published"` и реальную ссылку на
   источник в `sources[]`.
4. `npm run build` и проверить сверстанную страницу дела.
